# Prof Honey and the Lost Hominins

An archaeology adventure game for the Human Worlds anthropology lesson (Hominin Atlas). Students brush away dirt at 13 dig sites, read the evidence, and answer questions with Prof Honey as their guide.

Play it: https://hudsonlinemedia.github.io/lost-hominins/

The whole game is a single self-contained file, `index.html`, which can also be uploaded to Brightspace.
